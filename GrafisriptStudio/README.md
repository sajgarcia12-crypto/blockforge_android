# Grafisript Studio (Android)

Standalone Android app project for Grafisript. The first prototype includes a native dark code editor, run button, output console, a basic parser for `mostrar` and declarative properties, and local save/open of a `.graf` script.

## Build
Open this directory in Android Studio or use the GitHub Actions workflow. Requires Android SDK 35 and JDK 17.

**Prototype notice:** this is the first editor prototype, not yet the complete BlockForge Grafisript interpreter. The copied reference source remains untouched.
